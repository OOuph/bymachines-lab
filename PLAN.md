## Rollback

Every slice is one or a few commits; `git revert` returns to the previous working state. The database is append-only by design; a bad extraction is re-computed from raw JSON (`lab extract`), never by editing rows. A frozen panel is never edited; a mistake after the freeze becomes a new class with its own start date.
