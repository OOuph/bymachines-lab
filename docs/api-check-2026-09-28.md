# Vendor API check — 2026-09-28

Facts the adapters and `config/engines.yaml` stand on, read from the vendors' official pages on **2026-09-28**. Vendors change these without notice: re-verify before trusting a number older than a few weeks. Each line names its source page.

## OpenAI — Responses API + `web_search`

- Tool name `web_search` (current); `web_search_preview` is legacy. Guide: https://developers.openai.com/api/docs/guides/tools-web-search
- `user_location` = `{"type": "approximate", "country": "PT", "city": "Lisbon", "region": "Lisbon", "timezone": "Europe/Lisbon"}`; `type` is the only required field. **If omitted, the location defaults to the United States.** API reference: https://developers.openai.com/api/reference/resources/responses/methods/create
- `search_context_size`: `low | medium | high`, default `medium`.
- Response: `output[]` holds `web_search_call` items (`action.type == "search"`, `action.queries[]`; `action.query` is deprecated) and a `message` whose `content[0].annotations[]` are `url_citation {url, title, start_index, end_index}`. `include: ["web_search_call.action.sources"]` adds the full list of consulted URLs. `usage {input_tokens, input_tokens_details.cached_tokens, output_tokens, output_tokens_details.reasoning_tokens, total_tokens}`.
- Models (pricing page https://developers.openai.com/api/docs/pricing, per 1M tokens): `gpt-6-astra` $10 / $50 (rejects `reasoning.effort: none`), `gpt-6-sol` $2 / $10, `gpt-6-luna` $0.10 / $0.50. "No reasoning" = `reasoning: {"effort": "none"}`. Cached input: 10 % of the input price.
- Web search: **$10 per 1 000 calls** + search content tokens billed at the model's rates. Each `search` action counts.
- No search: omit `tools` (or `tool_choice: "none"`).
- Rate limits = the model's tier limits; Tier 1 ($5 paid): 500 RPM / 500 K TPM on Sol and Luna. https://developers.openai.com/api/docs/guides/rate-limits
- Not confirmed: whether search content tokens appear inside `usage.input_tokens` (calibrate with the first 10 calls against the usage dashboard).

## Perplexity — Agent API

- **Legacy Sonar chat completions lost support on 2026-09-27**; requests to `/chat/completions` or `/v1/sonar` are re-routed to Agent API presets (`fast` = `openai/gpt-6-luna` + `web_search`). https://docs.perplexity.ai/docs/agent-api/migrate-from-sonar/overview
- The only way to pin the Sonar model: `POST https://api.perplexity.ai/v1/agent` with `model: "perplexity/sonar"` and a `{"type": "web_search"}` tool. Models: https://docs.perplexity.ai/docs/agent-api/models · tool: https://docs.perplexity.ai/docs/agent-api/tools/web-search
- Tool options: `search_context_size` (`low | medium | high`), `user_location {country (ISO-2), region, city, latitude, longitude}`, `max_results` (1–50).
- Response: `output[]` typed steps — `search_results {results[] {title, url, date, snippet}}` and `message {content[].text}`; `usage {input_tokens, output_tokens, cost {input_cost, output_cost, tool_calls_cost, total_cost}}`. https://docs.perplexity.ai/api-reference/agent-post
- Prices: `perplexity/sonar` $0.25 / $2.50 per 1M; `web_search` tool $2.50 per 1 000 calls. https://docs.perplexity.ai/docs/getting-started/pricing
- Rate limit: Agent API Tier 0 = 1 request/s per organisation; 429 carries `Retry-After` and is not billed. https://docs.perplexity.ai/docs/admin/rate-limits-usage-tiers
- No search: omit the tool (do not use presets — their tools cannot be disabled).
- Not confirmed: that the Agent API's `perplexity/sonar` matches the pre-2026-09-27 Sonar engine in behaviour.

## Gemini — Grounding with Google Search

- `generateContent` is "legacy … fully supported" and keeps `groundingMetadata`; the Interactions API is recommended for new projects but has no location either. https://ai.google.dev/gemini-api/docs/generate-content/google-search · https://ai.google.dev/gemini-api/docs/google-search
- Request: `"tools": [{"google_search": {}}]`; **no location parameter for search grounding in the Gemini API** (only Vertex AI documents `toolConfig.retrievalConfig.latLng`).
- Response: `candidates[0].groundingMetadata {webSearchQueries[], groundingChunks[].web {uri, title}, groundingSupports[]}`; `uri` is a `vertexaisearch.cloud.google.com` redirect, `title` is the source domain (official example). Resolving redirects is not documented.
- Models: `gemini-3.8-flash` (stable), `gemini-3.1-pro-preview` (preview). https://ai.google.dev/gemini-api/docs/models
- Prices: `gemini-3.8-flash` $0.75 / $3.75 per 1M through 2026-12-31 (then $1.50 / $7.50); grounded context is not charged as input. Grounding: **not available on the free tier**; paid tier 5 000 free search queries per month across 3.x models, then $14 per 1 000 queries — billed per executed search query, several per prompt possible. https://ai.google.dev/gemini-api/docs/pricing
- Terms (effective 2026-03-23): users "will not … cache, frame, syndicate, resell, analyze, train on, or otherwise learn from Grounded Results or Search Suggestions" and may not use "programmatic or automated means to collect Links" or "use Links to build an index". https://ai.google.dev/gemini-api/terms — owner decision required (SPEC §12 Q6).
- No search: omit `tools`. With the tool attached the model decides whether to search: classify by non-empty `webSearchQueries`.

## DataForSEO — Google AI Mode (SERP API)

- Endpoints: `POST /v3/serp/google/ai_mode/live/advanced` (live, $4 per 1 000); `POST /v3/serp/google/ai_mode/task_post` + `GET /v3/serp/google/ai_mode/task_get/advanced/{id}` (standard $1.20 per 1 000, ≈5 min; priority $2.40). https://docs.dataforseo.com/v3/serp/google/ai_mode/live/advanced/ · https://dataforseo.com/pricing/google-serp/google-ai-mode-serp-api
- Body: `[{"keyword": "...", "location_code": 1011742, "language_code": "en", "device": "desktop"}]`. City codes (CSV 2026-09-01): Lisbon 1011742, Madrid 1005493, Limassol 1003698, London 1006886, New York 1023191. https://docs.dataforseo.com/v3/serp/google/locations/
- Response: `result[0].items[0]` of type `ai_overview` with `markdown` (whole answer, inline `[[n]](url)` markers) and `items[]` of `ai_overview_element {text, markdown, links[], references[] {source, domain, url, title, text}}`; sources are per element, aggregate in order. The task carries its `cost`.
- Account: minimum payment $50 (does not expire), $1 trial credit, free sandbox at `sandbox.dataforseo.com` with dummy data. https://dataforseo.com/help-center/minimum-payment
- Bing index count for the census: `POST /v3/serp/bing/organic/live/advanced` with `site:domain`, field `se_results_count`; the operator multiplies the price ×5 (≈$0.01 live). https://docs.dataforseo.com/v3/serp/bing/organic/live/advanced/
- Not confirmed: AI Mode availability for Portugal / Spain / Cyprus locations (docs defer to Google's country list); European Portuguese language code (`pt-BR` only in the documented example).
